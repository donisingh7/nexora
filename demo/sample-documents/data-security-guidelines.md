# Data Security Guidelines

These guidelines describe the minimum security practices expected on any device used for company work.

## Device encryption

All laptops must have full-disk encryption enabled before they are used to access company systems. IT verifies encryption status during device setup and during periodic compliance checks.

## Screen locking

Screens must be configured to lock automatically after five minutes of inactivity. Manually locking the screen before stepping away from a device is required in shared or public spaces.

## Password and authentication

Passwords must be at least twelve characters and unique to each system; a password manager is provided for this purpose. Multi-factor authentication is required for email, the VPN, and any system that stores customer data.

## Reporting an incident

Suspected security incidents, including lost devices, phishing attempts, or unauthorized access, must be reported to the security team within one hour of discovery. Do not attempt to investigate or remediate a suspected breach independently.

## Data handling

Confidential data should not be copied to personal devices, personal cloud storage, or removable media. Data classified as confidential or above must stay within approved company systems at all times.
